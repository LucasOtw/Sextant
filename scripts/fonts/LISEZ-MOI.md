# Polices de l'image de partage

Fichiers utilisés par `scripts/og-image.html` pour produire `src/app/opengraph-image.png` sans requête vers Google.
Ce sont les sous-ensembles latins (polices variables, WOFF2) que `next/font/google` télécharge au build pour le site
(`src/app/fonts.ts`) : les mêmes dessins que les pages.

- `Fredoka-latin.woff2` : Fredoka 2.001, Copyright 2016 The Fredoka Project Authors (https://github.com/hafontia/Fredoka-One).
- `Nunito-latin.woff2` : Nunito 3.602, Copyright 2014 The Nunito Project Authors (https://github.com/googlefonts/nunito).

Les deux sont distribuées sous la SIL Open Font License, version 1.1 (https://openfontlicense.org), qui en autorise la
redistribution avec leur avis de copyright. Texte de la licence : `OFL.txt` ; les fichiers portent aussi leur copyright
et l'adresse de la licence dans leurs métadonnées (table `name`).
